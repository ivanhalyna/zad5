Zadanie 4 - Halyna

1) kiedy powstał JavaScript (podaj datę).

JavaScript został stworzony w 1995 roku. W grudniu 1995 roku został zaimplementowany w najnowszej wówczas wersji Navigatora.

2) dlaczego jest to język skryptowy

JavaScript jest językiem skryptowym, czyli interpretowanym. Nie musi zostać skompilowany do kodu maszynowego, aby można było zobaczyć efekty jego działania. Wystarczy przeglądarka internetowa, która obsługuje ten język.

3) gdzie jest wykonywany JS (klient lub serwer)

JavaScript może być wykonywany w przeglądarce internetowej po stronie klienta, a także na serwerze, np. przy użyciu Node.js.

4) dlaczego jest JS to bezpieczne narzędzie

Ze względów bezpieczeństwa JavaScript ma znacznie ograniczone uprawnienia dostępu do zasobów komputera, na którym przeglądana jest dana strona.

5) czy jest to język obiektowy, jeśli tak to dlaczego.

Tak. JavaScript jest językiem obiektowym, ponieważ wykorzystuje definicje obiektów, metod i zdarzeń, które mogą być zastosowane do opisu właściwości obiektów. Obiekty posiadają strukturę określaną przez DOM (Document Object Model).

6) wymień zalety JS:

Zaleta1: Prostota – JavaScript jest relatywnie łatwy do opanowania.

Zaleta2: Duża popularność – w Internecie można znaleźć miliony praktycznych przykładów.

Zaleta3: Uniwersalność oraz możliwość odciążenia serwerów i ograniczenia ilości zbędnych danych przesyłanych między serwerem a przeglądarką klienta.

7) Framework to:

Framework to rodzaj programu do tworzenia innych programów w JavaScript.

8) Do aplikacji mobilnych można użyć Framework

React Native.

9) Aplikacje responsywne to:

Aplikacje, które mogą dostosowywać sposób wyświetlania treści do bieżącego rozmiaru ekranu. Przy użyciu CSS i HTML można zmieniać rozmiar, ukrywać, zmniejszać, powiększać lub przenosić treści, aby wyglądały dobrze na dowolnym ekranie.

10) Przepisz linie kody pod nimi wytłumaczenie jak działa ten fragment kodu

<input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')">

Linia tworzy przycisk formularza. Atrybut type="button" określa typ przycisku, name="przycisk" nadaje mu nazwę, value="Nowa Strona" ustawia napis na przycisku, a onclick="WinOpen(' ')" powoduje wywołanie funkcji WinOpen po kliknięciu przycisku.

11) Przepisz linie kody pod nimi wytłumaczenie jak działa ta ten fragment kodu

window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");

Instrukcja otwiera nowe okno lub kartę z plikiem obraz.html. Nazwa okna to okienko.

toolbar=no – ukrywa pasek narzędzi.

directories=no – ukrywa przyciski katalogów.

menubar=no – ukrywa pasek menu.

height=280 – określa wysokość okna na 280 pikseli.

width=160 – określa szerokość okna na 160 pikseli.

top=200 – określa położenie okna 200 pikseli od górnej krawędzi ekranu.

left=200 – określa położenie okna 200 pikseli od lewej krawędzi ekranu.

12) Opisz następującą instrukcję window.close()

Instrukcja window.close() zamyka bieżące okno przeglądarki, jeżeli zostało otwarte przez skrypt.
